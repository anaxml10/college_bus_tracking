## 📌 Project Architecture
This repository hosts the full source code for the **College Bus Tracking & Management System** built with **Java Spring Boot**, **Thymeleaf**, and **Leaflet OpenStreetMap API**.

### Roles Implemented:
1. **Admin Portal (`/admin`):** Complete fleet control, driver-bus route allocation, and student fee status tracking.
2. **Driver Portal (`/driver`):** GPS Telemetry streaming engine capturing real-time coordinates.
3. **Student Portal (`/student`):** Interactive map UI displaying live bus tracking, driver info, and dynamic ML-driven ETA.
